== OpenDJ 5.2.0

OpenDJ 5.2.0 was published on 21 October 2026. These notes describe that released version. Documentation built from a development branch can also describe changes intended for a later release; a `SNAPSHOT` build is not a published release.

The link:https://github.com/OpenIdentityPlatform/OpenDJ/releases/tag/5.2.0[5.2.0 release record] is the authoritative list of release assets and changes. The link:https://github.com/OpenIdentityPlatform/OpenDJ/compare/5.1.2...5.2.0[complete comparison with 5.1.2] provides the corresponding source history. For newer releases, consult the link:https://github.com/OpenIdentityPlatform/OpenDJ/releases[release list].

=== Selected Changes

The release includes the following changes, among others:

* Security fixes for the DSML gateway, OAuth2 file token authorization, LDAP connection handling, and access control for sort and virtual list view (VLV) requests. Review the link:https://github.com/OpenIdentityPlatform/OpenDJ/security/advisories[published security advisories] for affected versions, impact and remediation details.
* Directory and replication reliability fixes, including startup failure reporting when a replication server cannot open its port or changelog, and persistent-search notification handling.
* JDBC backend fixes for Microsoft SQL Server upsert conflicts and deadlocks.
* Docker improvements for arbitrary user IDs in group 0, secret handling, health checks, background replication joining and upgrades from a released image.
* REST to LDAP fixes for HTTP Basic credentials and bind templates, and reloading file-based key stores and trust stores when their files change.

This is a summary, not a second copy of the full change list. Use the release record to identify individual fixes and their pull requests.
